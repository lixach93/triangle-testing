
# Triangle Testing

## Project Description

A Java console application that checks whether three positive integers
can form a triangle and determines its type.

Supported triangle types:
- Right-angled triangle
- Acute-angled triangle
- Obtuse-angled triangle

## Technologies

- Java 17
- Maven
- JUnit 5

## Running the Application

Run the Main class from your IDE.

Enter three positive integers separated by spaces.

## Running Unit Tests

Execute:

```bash
mvn clean test
```

## Testing

The project includes parameterized JUnit 5 tests covering:
- Input validation
- Triangle existence
- Triangle classification
- Boundary conditions
